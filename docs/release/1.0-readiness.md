## Blockers

1. **Heartbeats fail once a satellite has replicated.** `fleet.JournalService.Ingest` returns `notimpl.Err("6.5 journal ingest")`. `Beat` turns every error except `ErrInvalid` into 500. The satellite sends at least one journal record whenever its journal has any (`internal/satellite/state/report_journal.go`), and every replication writes records. Because the error returns before the session step, session renewals, rotated credentials and events in that answer never reach the satellite. Fix: implement 6.5 (the 15 pending tests describe it), or as a stopgap map `notimpl` to a journal ack error in `Beat`. The heartbeat then answers 200, and the satellite drops each batch after three rejections, so journal records are lost but nothing else is.
