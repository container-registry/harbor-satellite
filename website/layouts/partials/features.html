Why Harbor Satellite

Built for Sites You Cannot Babysit

Extend your container registry to every edge location with reliability, security and central management.

Reliability

Images are prepositioned in persistent storage at each edge location, so they stay on site when the network goes down.

Security

SPIFFE/SPIRE zero-trust identity with automatic credential rotation. No static secrets shipped to edge devices.

Fleet Management

Centrally manage image distribution across hundreds of edge locations. Group images and assign them to satellites.

Air-Gapped Ready

Same fleet, same process. Air-gapped sites import signed, differential OCI bundles. Temporarily disconnected sites keep their replicated content on local disk and resume replication on reconnect.

CRI Integration

Configure containerd, Docker, CRI-O, and Podman to use an edge BYO registry as a mirror with upstream fallback, or deliver images straight into k3s and RKE2.

Lightweight

Single binary with an ORAS-backed OCI image layout. Minimal resource footprint for constrained edge environments.
